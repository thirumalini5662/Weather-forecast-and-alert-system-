# 🌦️ Weather Forecast App

## Overview
This app fetches real-time weather data using an API and displays it in a dashboard.

## Features
- City-based weather search
- Temperature, humidity, wind
- Forecast
- Chart visualization

## Tools
- Python
- Streamlit
- Requests API

## Run
python -m streamlit run app.py
